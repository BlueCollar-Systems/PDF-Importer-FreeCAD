# FreeCAD PDF Importer 4.0.102

Foundation drawings such as S-505 can complete import when the PDF has sparse object tables and SVG whitespace glyphs. The release includes the fixes already integrated into main as well as the remaining September host-coordinate and audit fixes.

- Restores Unicode character maps for supported embedded symbolic TrueType subsets using the PDF's own ToUnicode data, preserving original outlines.
- Recognizes proven empty SVG glyph placements without treating them as lost text; malformed or visible paths remain subject to the existing failure checks.
- Preserves disconnected PDF subpaths and the existing raster-underlay/text-delivery safeguards.
- Normalizes sheet bounds and host coordinates consistently across the Python importers.
- Keeps optional interactive-feature auditing nonfatal and records partial inspection of sparse object tables.

The Windows ZIP and installer continue to use the existing pinned runtime, privacy, smoke and reproducibility gates. Local/native verification details are retained in the coordinated release evidence; the release pipeline must pass before public assets are considered ready.

Validation: 917 tests passed and 18 skipped on Python 3.12. FreeCAD 1.1.3 completed the S-505 import with 2,415 objects; native save/reopen preserved the complete shape inventory. This verifies the tested drawing and failure classes, not universal PDF support.
