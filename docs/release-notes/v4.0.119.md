# FreeCAD PDF Importer 4.0.119

This release brings together the fixes made since 4.0.115, the last published
version. Versions 4.0.116, 4.0.117 and 4.0.118 were never published on their
own; their fixes are included here.

## What changed

- **Saved drawings with pictures reopen more safely on Windows.** The importer
  protects each imported picture against a known FreeCAD graphics fault (in
  Coin versions older than 4.0.8) as soon as a saved drawing starts to load,
  not later. Picture pixels, position and your display settings are kept.
- **The paper sheet comes back after reopening.** When a saved drawing is
  reopened, the paper view is rebuilt if it is missing. Display modes and
  visibility you set yourself are kept.
- **Drawings imported without the FreeCAD window** (for example from a script)
  and then saved now open correctly in the desktop app: restoring waits until
  FreeCAD has finished loading the file.
- **Zoom to fit** after an import turns off view animation only for that one
  view and always turns it back on, even if fitting fails. Your FreeCAD
  preferences are not touched.

## Known limits

- **Desktop reopen of a saved drawing with pictures has not been confirmed for
  this exact version.** The fix aims at a crash or missing picture seen when
  reopening such a drawing in the FreeCAD window. The automatic checks passed
  and a FreeCAD 1.1.4 test without the window (described below) kept every
  object, but a hands-on desktop open, save, close and reopen of 4.0.119 has
  not been done yet. If a saved drawing crashes or shows a blank picture when
  you reopen it, please send the import report.
- Password-protected PDFs must be unlocked before import.
- Scanned PDFs (pictures only) give no editable lines.
- Drawings with very complex clipping or deeply nested parts can come in
  partly.
- Very large drawings (more than about 10,000 items) import slowly.
- A damaged embedded font can make some text fall back to a plainer form; the
  import report lists every such item.
- FreeCAD needs Python 3.10 or newer: FreeCAD 0.20 and older, and the official
  FreeCAD 0.21 Windows installer, are not supported.

## Install

Run `FreeCAD-PDF-Importer-Setup_v4.0.119.exe` (no administrator mode needed),
or extract `FreeCAD-PDF-Importer_v4.0.119.zip` into the FreeCAD `Mod` folder.
Restart FreeCAD and choose **PDF Vector Importer** from the workbench list.

## Validation

- Release gate: 2,733 tests passed and 27 skipped; the ZIP, two reproducible
  installers and the bundled-runtime smoke check passed in the build-only
  release run.
- FreeCAD 1.1.4 (FreeCADCmd, no window) with the exact build-only ZIP: two
  fictional test drawings (a three-sheet vector drawing, and a sheet with a
  picture, lines and embedded-font text) and one real shop sheet imported with
  status success and no degraded text. Each was saved, closed and reopened,
  both in the same session and in a fresh FreeCAD process; every object,
  shape count, size and picture came back unchanged.

This verifies the tested drawings, not every PDF.
